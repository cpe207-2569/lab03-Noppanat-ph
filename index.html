นพณัฐ พรหมเสน
ผมนายนพณัฐ พรหมเสน ชื่อเล่น ปอนด์
ศึกษาที่มหาวิทยาลัยเชียงใหม่ คณะวิศวกรรมศาสตร์ สาขาคอมพิวเตอร์ เกียร์ 56

ความสามารถของฉัน

การเขียนโปรแกรม

ฉันสามารถเขียนโปรแกรมในภาษา C++ HTML และ Python ได้และยังพร้อมที่จะเรียนรู้ภาษาอื่นๆต่อไป

ความคิดสร้างสรรค์

ฉันสามารถออกแบบสิ่งต่างๆอย่างสร้างสรรค์ได้ และศึกษาดูการออกแบบของสิ่งต่างๆ

การสื่อสาร

ฉันสามารถเข้าร่วมกับผู้อื่นได้ไว ชอบชวนคุย สามารถเป็นได้ทั้งผู้ตามและผู้นำ
